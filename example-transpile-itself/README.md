There's no real use case for this (beyond a proof of concept that it can compile itself) because
- the setup for users is more complicated (build node-elm-to-swift, install swift, wait a minute for optimized compilation)
- my laptop freezes and crashes even trying to compile because `swiftc` is very memory hungry
